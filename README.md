# Endure & Survive — Prototype README

### Overview

Endure & Survive is a 2D top-down educational survival game developed in Godot 4.5.1.
The game teaches essential outdoor survival skills—fire-starting, shelter-building, and navigation, while keeping gameplay engaging and fun.
Players will complete 3 levels consisting of collect materials, completing interactive minigames, and progressing through survival challenges.

## Level Descriptions

### Fire Starting

* Player learns the essential ingredients of fire: tinder, kindling, and fuel.
* A drag-and-drop minigame reinforces correct resource selection.

### Shelter Building

* Player collects logs to construct a lean-to shelter.
* A drag-and-drop minigame has five-step animated build sequence that visually explains the construction process.

### Orienteering

* Player moves across the map to find key locations.
* Direction prompts teach basic navigation skills.

## How to Build & Run

1. Install Godot 4.5.1.
2. Clone the project repository:
   
  `git clone https://github.com/BenHoule/SWE-EndureAndSurvive.git`

3. Open Godot → Import → Select the project folder.
4. Click Run Project.

**Once the project is initialized, it can be easily be exported to Mac, Windows, or Linux through the Godot editor.**

### Alternatives
*  Open the game in your brower: https://benhoule.github.io/
  **This requires no additional packages or plugins and runs on Mac, Windows, and Linux.**


## Known Issues & Bugs

*  When accessing the game on a hosted service (e.g. through https://benhoule.github.io/) the browser may cache the game version. Site data must be cleared to access updated versions of the game.
*  *  **Normal browser shortcuts (e.g f12 / ctrl+shift+i) are intercepted by Godot** 
*  *  *(From browser) > "Settings and more" > "More tools" > "Developer tools"*
*  *  *(From Dev tools) > Application > Storage > Clear site data*
*  In the web version the drag-&-drop items get offsetted from the cursor
